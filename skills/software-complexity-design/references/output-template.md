## 工件五：可运行性证明与交付

### 请求幂等

| 请求类型 | 预期结果 | 新副作用 |
|---|---|---|
| 同一幂等键、参数相同 | 复用结果或返回处理中 | 不允许 |
| 同一幂等键、参数不同 | 返回参数冲突 | 不允许 |
| 新幂等键、业务动作重复 | 按业务唯一性规则返回已存在或冲突 | 不得默认允许 |

### 恢复与收尾

| 失败或变化 | 状态维护者 | 补采/重新加工 | 已消费结果处置 | 重跑批次或版本 | 阻断/重开收尾条件 | 人工入口 |
|---|---|---|---|---|---|---|
| 重复接入 |  |  |  |  |  |  |
| 迟到或缺失数据 |  | 补采来源、批次、去重键 | 无消费 / 已消费范围 |  |  |  |
| 输入修正或规则变化 |  | 新输入版本 / 新规则版本 / 新结果版本 |  |  |  |  |
| 核心处理失败 |  |  |  |  |  |  |
| 下游已消费后发现错误 |  |  | 回退 / 补偿及依据 |  |  |  |
| 下游交付失败 |  |  |  |  |  |  |

恢复动作必须区分：

| 动作 | 适用条件 | 结果 | 前置与顺序 |
|---|---|---|---|
| 补采 | 原始输入迟到或缺失 | 补齐带原来源和业务时间的数据 | 先确认缺口与去重，再决定是否重新加工 |
| 重新加工 | 输入修正或规则版本变化 | 生成可追溯的新结果版本 | 不覆盖已发布/已消费结果 |
| 回退 | 副作用可逆且由责任方控制 | 恢复到明确前态 | 先限定已消费范围和幂等保护 |
| 补偿 | 已跨系统或无法原地撤销 | 生成前向修正并保留审计链 | 先确认目标状态与对账方式 |
| 重跑 | 输入与副作用已妥善处置 | 从明确检查点重新执行 | 在补采/重新加工及回退/补偿之后执行 |

### 推进清单

1. 先关闭影响边界和所有权的待确认项；
2. 再确认稳定契约、错误和版本；
3. 然后设计恢复、监控和验证；
4. 最后进入详细实现。
