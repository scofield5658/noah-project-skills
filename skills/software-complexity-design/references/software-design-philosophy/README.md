# 软件设计哲学资料导航

本目录为 `software-complexity-design` 提供按需读取的概念资料，不独立触发。

## 文件职责

- [principles-and-red-flags.md](principles-and-red-flags.md)：独立表述的复杂性控制原则和危险信号。
- [chapter-notes.md](chapter-notes.md)：按主题重新组织的研读笔记，不复刻第三方书籍章节或案例库。
- [team-design-insights.md](team-design-insights.md)：面向大型团队的设计与协作建议。
- [source-and-method.md](source-and-method.md)：来源、许可边界、研读方法和术语说明。

具体架构动作见上一级 [software-design-philosophy-integration.md](../software-design-philosophy-integration.md)。

## 版权边界

这些文件受相关著作启发，但使用本仓库独立编写的总结、问题和通用案例。没有明确再分发许可的原文、译文、章节复述、图表和案例叙述未被复制。

第三方书名、作者名和短技术术语仅用于来源归因。本目录不再分发第三方受保护表达；来源与采用路径见 [source-and-method.md](source-and-method.md)。

## 维护规则

- 不把公开可访问误认为允许复制或再许可。
- 原始来源变化时更新 `source-and-method.md`，不要静默改变术语含义。
- 实践建议不是任何组织的既有强制规范；是否采用取决于当前系统证据和约束。
