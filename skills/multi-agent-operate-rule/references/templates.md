# 模板

字段名可以按宿主调整，但语义必须出现在持久材料里，不能只留在协调者的上下文中。栏位分三类：

- **必填**：每次使用该模板都要回答。没有发生时写“无”，不要删栏。
- **按场景**：只有场景出现时填写。场景未出现则写“不适用”。
- **不适用**：该契约或该任务用不到的内容，写明不适用的原因。

简单任务只保留真正使用的模板。不要为了凑数生成多份重复报告。

## 任务说明

执行者没有主会话历史时，只靠这一份和固定输入开工。

| 栏位 | 要求 | 填写 |
|---|---|---|
| 任务关联 | 必填 | 整体目标、当前协调者、返回入口 |
| 目标与范围 | 必填 | 要解决什么；不包含什么 |
| 完成契约 | 必填 | 调查或报告交付 / 实现并自测 / 整改至满足标准 |
| 输入依据 | 必填 | 资料、准确版本、哪些必须读正文 |
| 允许动作 | 必填 | 可读、可改、可执行的范围；需另行确认的动作 |
| 依赖 | 必填 | 开始前必须成立的条件；没有则写“无” |
| 交付物 | 必填 | 交出什么、放在哪里、如何识别版本 |
| 完成条件 | 必填 | 必须完成的检查；负面结论是否算有效交付 |
| 返回与接续 | 必填 | 如何通知协调者；失败或受阻如何报告 |
| 兼任说明 | 按场景 | 协调者兼任执行时，写明兼任的段落 |
| 专业技能 | 按场景 | 允许使用的技能名称和适用场景；没有则写“无” |
| 并行组 | 按场景 | 共享的只读输入版本，以及本任务独占的输出位置 |

未知不能空着。写成“未知”，并停止依赖该栏的派发。

## 成果交付

| 栏位 | 要求 | 填写 |
|---|---|---|
| 任务关联 | 必填 | 对应哪一份任务说明 |
| 成果位置与版本 | 必填 | 可读取的位置和准确版本 |
| 状态 | 必填 | 候选，待复核 / 已采用 |
| 执行情况 | 必填 | 完成、失败、跳过或未执行的事项 |
| 质量结论 | 必填 | 是否满足要求、证据、剩余风险 |
| 验证证据 | 必填 | 检查了什么；调查契约写核对范围 |
| 接受决定 | 按场景 | 只有本任务约定要接受时填写决定人、版本和结论 |
| 代码版本 | 按场景 | 实现或整改契约填写准确提交和必要路径 |

不适用：

- 调查或报告交付不要求代码版本。
- 实现并自测不能用建议报告代替代码版本和自测证据。
- 整改至满足标准不能把“已发现问题”填成通过。

## 交接记录

| 栏位 | 要求 | 填写 |
|---|---|---|
| 目标、范围、阶段、完成条件 | 必填 | 接手人确认当前做到哪 |
| 固定输入 | 必填 | 已读来源和版本 |
| 已完成工作 | 必填 | 准确成果版本和验证结果；没有则写“无” |
| 未完成事项 | 必填 | 失败尝试、需要重核的判断；没有则写“无” |
| 已确认决定 | 必填 | 原始出处和适用范围；没有则写“无” |
| 外部操作 | 必填 | 已产生的操作，或结果未知的操作；没有则写“无业务写入” |
| 下一步 | 必填 | 责任人、第一个动作、前提、成功判断 |
| 自身发布标识 | 不适用 | 正文不预写尚未生成的版本号；发布后由回执补充 |

接收回执由接收者另写一段，附在同一次交接的返回里：

| 栏位 | 要求 | 填写 |
|---|---|---|
| 输入是否可用 | 必填 | 可用，或受阻原因 |
| 实际版本 | 必填 | 打开后看到的版本 |
| 缺口 | 必填 | 没有则写“无” |
| 下一步 | 必填 | 接收者接下来的一个动作 |

回执不是业务批准。

## 人工决定请求

| 栏位 | 要求 | 填写 |
|---|---|---|
| 关联 | 必填 | 问题、所依据的版本、批准范围 |
| 问题 | 必填 | 需要人决定的具体事项 |
| 背景证据 | 必填 | 指向持久材料的版本，不贴整段会话 |
| 可选方案 | 必填 | 列出实际可选项；只有一个可选项时写明原因 |
| 建议与影响 | 必填 | 建议选哪一个，会影响哪些动作 |
| 暂停与可继续 | 必填 | 等待期间停止什么，现有授权内还能做什么 |
| 反馈通道 | 必填 | 原始意见留在哪里 |
| 恢复入口 | 必填 | 新的协调运行读取哪份记录，由谁启动 |
| 合并询问 | 按场景 | 仅当同一人、同一版本、同一权限范围 |

不适用：不要把合并、部署或发布批准并进范围不同的问题。

## 恢复检查点

| 栏位 | 要求 | 填写 |
|---|---|---|
| 任务关联 | 必填 | 整体目标和当前协调者 |
| 已读材料 | 必填 | 固定版本；读不到的材料单独列出 |
| 实际状态 | 必填 | 已执行、未执行、未知 |
| 操作对账 | 必填 | 请求对象、输入版本、执行结果、解析结果、真实回执、未知项 |
| 第一个未完成动作 | 必填 | 动作、前提；还不能做时写缺少的条件 |
| 不再重放 | 必填 | 哪些操作不会重试，以及原因 |
| 未持久化工作 | 按场景 | 无法恢复或需要重做；重做前仍要排除重复副作用 |

不适用：不要把会话摘要填进“已读材料”来代替成果。
