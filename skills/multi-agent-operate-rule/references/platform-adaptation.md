# 平台适配

本 skill 描述协作行为。宿主提供执行能力。同一个产品可以兼任几项职责，但不因此变成调度器或批准来源。

本仓库给出的具体适配只有**人工中转**。它不包含事件驱动平台的接入、命令或安装步骤。宿主自己已经有事件时，协调者仍按下面的限制处理，不能把本 skill 读成某个平台已经接好。

## 职责边界

| 组成 | 负责什么 | 不要把它当成 |
|---|---|---|
| 协作技能 | 工作顺序、角色边界、交付契约、异常处理和检查清单 | 调度器、权限系统或常驻进程 |
| 任务系统 | 任务身份、指派、依赖、状态和交互记录 | 完整成果仓库，或质量已经通过的证明 |
| 执行环境 | 模型、工具、专业技能和实际操作 | 跨运行自动保留状态的保证 |
| 交接存储 | 固定输入、成果版本、决定依据和恢复记录 | 自动唤醒服务，或批准的来源 |
| 代码与制品系统 | 代码版本、补丁、构建和发布制品 | 整体任务已经完成 |
| 人工交互通道 | 提出问题、接收反馈、保存决定出处 | 默认可靠的通知或已读证明 |

同一任务可以在多个系统里留关联。每类事实只认一个权威来源，不自动双向镜像全部状态。任务系统保存摘要和引用即可，不复制整份报告。

交接存储只要满足当前用法所需的持久性、版本定位和访问条件。它可以是已有服务，也可以是受控文件。不指定供应商，也不要求新建服务。运行结束会销毁本地环境时，交接位置必须能在新运行中重新打开。

## 触发条件

准备派单、发布交接、等待反馈、查询外部副作用或启动下一轮之前，只核对这一步要用到的能力。不要求每次运行扫描全部服务、仓库或权限。控制台里某个字段为空，也不能单独证明环境没有这项能力。

## 能力核对

| 这一步需要 | 核对什么 | 不具备时 |
|---|---|---|
| 任务指派与依赖查询 | 实际任务身份、负责人、状态和受理结果 | 改成已经登记的人工交接，不伪造已派单 |
| 持久交接与版本读取 | 新运行能否读取指定版本，并识别作者和归属 | 停止依赖交接的自动流程，标明还没有可靠交接 |
| 事件或反馈触发 | 哪类事件会启动谁，是否可能重复或丢失 | 写明人工启动方式，不用常驻等待冒充触发 |
| 原始反馈读取 | 能否取得决定人、依据和原文 | 保持待确认，不按转述放行 |
| 操作结果查询 | 能否核实真实的外部副作用 | 结果未知时暂停相关写入 |
| 代码与专业工具 | 当前任务所需的读取、验证或操作入口 | 报告实际缺口，保留已经能完成的部分 |

这些名字不是要求提供同名接口。使用宿主现成工具，并说明它实际表达的语义。不编造命令，不安装未获授权的替代服务。

## 两种用法

**平台驱动协作**要求宿主负责派发、事件触发和运行生命周期。技能只规定角色如何消费事件、处理成果和交还控制权。事件可能重复或乱序，协调者仍按 [recovery-and-reconciliation.md](recovery-and-reconciliation.md) 对账。本仓库没有附带这种适配。

**人工中转协作**由人根据任务说明和持久交接材料启动下一位执行者。每一次交接都写明人工责任人。可以核对接力和产物，但不能称为自动流转。

两种用法的交付要求相同。从一种换成另一种时，保留任务关联和版本，不为了换工具另起一条没有关联的任务链。

分布式委派和本地子 Agent 也不能在未声明的情况下互相替换，以免形成隐藏调度链。

## 人工中转示例

下面的例子只说明人工中转。人物、文件标识和版本都是虚构的，不对应真实服务。完整剧情见 [worked-example.md](worked-example.md)。

声明：

- 支持的组织方式：人在独立执行者之间转交持久材料。
- 不支持：事件唤醒、后台轮询、分布式锁，以及把本地子 Agent 的隐式上下文当成已派单。
- 共享磁盘或同一次聊天不会取消版本和责任要求。

一次接力：

1. 协调者把任务说明发布到约定的持久位置，版本记为 `task-brief-r1`。
2. 人把该版本的引用交给执行者，并写明自己是这次启动的责任人。
3. 执行者只读 `task-brief-r1` 点名的输入，把候选交接发布为 `handoff-r1`。
4. 执行者给人一份摘要和 `handoff-r1` 的引用。人再把它交给协调者。
5. 若无人把引用交到下一手，状态是“等待人工启动”，不是“已自动接续”。

这个示例没有命令、安装步骤或凭据。平台权限和工具配置是使用前提，不在本 skill 里重建。

## 依赖声明

当前发布内容是纯指导，没有本地运行时依赖，也没有辅助脚本。

若以后另加脚本或平台适配器，那个变更需要单独声明运行时版本、系统工具、第三方包、服务接口、配置来源、检查方式和缺失时的处理。本文件不预留这些接口。

## 完成标准

- 当前动作所需能力已经核对，做不到的步骤有降级方式或已经停止。
- 人工中转没有被写成自动流转。
- 没有为了补能力而发明命令、服务或凭据方案。
- 事实的权威来源清楚，任务状态没有被当成质量证明。
