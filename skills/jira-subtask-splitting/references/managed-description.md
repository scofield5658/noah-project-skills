# 主任务受控描述字段

本 Skill 只管理以下主任务字段：

```text
---
是否涉及前端改造：是
是否有性能风险：否
测试建议：按需求点测试
```

产品说明、技术备注、Wiki/文档链接、历史文本、列表、代码块和这三项字段之外的任何文字都不属于本 Skill 的可修改范围。

## 生成补丁

1. 读取原始描述并逐行定位三个精确标签。
2. 每个标签至多出现一次时，只替换该行冒号后的值；保留该行前缀、其他行、空行和顺序。
3. 三个标签均缺失时，在描述末尾以空行和 `---` 追加完整块。
4. 标签部分缺失时，仅在末尾追加缺失标签；不复制已经存在的标签。
5. 任一标签出现多次、值不可识别或描述无法可靠读取时，停止自动补丁并列为待确认项。

## 值来源

| 字段 | 可用值 | 来源 |
| --- | --- | --- |
| 是否涉及前端改造 | 是 / 否 | 本次 Manifest 是否包含前端工作项；与现有值冲突时展示补丁并等待确认。 |
| 是否有性能风险 | 是 / 否 | 用户逐个主任务明确确认。交易查询、历史列表、分页、大数据量和批处理只用于提醒，不能自动给出结论。 |
| 测试建议 | 文本 | 默认“按需求点测试”；用户提供其他建议时以用户值为准。 |

## 已有子任务描述

对已有子任务，只有在用户明确要求维护 `所属模块`、`任务维度`、`工作主题`、`工作范围` 等结构化元数据时才更新。更新时仅改这些精确标签；所有其他内容只允许保留或在末尾追加，绝不覆盖产品或技术同事的补充说明与文档链接。
